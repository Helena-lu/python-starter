# python-starter

我的 Python 起步项目，用来练习 Python 与 GitHub 的配合使用。

## 运行

```bash
python main.py
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 主程序：简易计算器 |
| `.gitignore` | 告诉 git 哪些文件不用上传 |
| `README.md` | 项目说明（就是本文件） |

## 日常改动 → 上传 GitHub 三条命令

```bash
git add .                      # 把改动加入暂存区
git commit -m "这次改了什么"    # 生成一次提交记录
git push                       # 推送到 GitHub
```
